Commands to run:

# 1. Rebuild + push both images (adjust the checkout path if yours differs)
docker build -t local-registry:5000/speech-mcp:v2 speech-mcp
docker push local-registry:5000/speech-mcp:v2

docker build -f demo/Dockerfile -t local-registry:5000/speech-demo:v2 \
  --build-context patches=demo \
  ../../huggingface/speech-to-speech/demo
docker push local-registry:5000/speech-demo:v2

# 2. Deploy
kubectl -n speech apply -f k8s/speech-mcp/deployment.yaml
kubectl -n speech apply -f k8s/demo/deployment.yaml
kubectl -n speech rollout status deployment/speech-mcp
kubectl -n speech rollout status deployment/speech-demo

# 3. Verify
./scripts/smoke-test.sh mcp
curl -k -X POST https://192.168.10.31:30443/api/mcp/call \
  -H 'Content-Type: application/json' \
  -d '{"name":"local_time","arguments":{"timezone":"Asia/Tokyo"}}'

Then, in the browser, ask something like "what time is it in Tokyo?" or "search the web for today's weather in Berlin" and confirm you get a real, current answer (and check the tool-call indicator in the chat UI). Let me know how that goes and I'll investigate if anything's off.
